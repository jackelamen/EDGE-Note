# Daily Use QA

Run this pass when EDGE Note is deployed and you are ready to use it as the real notes home for the day.

## Morning Start

1. Open the app on desktop.
2. Log in.
3. Confirm Home loads without showing editor panels behind it.
4. Confirm Recent notes and Notebooks show expected content.
5. Open the Notes tab and select a recent note.
6. Confirm the editor, tasks, history, AI, attachments, backup, and security tools are reachable.

## Capture Flow

1. Create a note.
2. Add a real title.
3. Type at least two paragraphs.
4. Add a checklist item.
5. Add tags.
6. Save with the Sync button.
7. Refresh the page and confirm the note remains.

## Find Flow

1. Search by title.
2. Search by body text.
3. Save one search.
4. Clear search.
5. Reopen the saved search.
6. Delete the saved search when done.

## Safety Flow

1. Edit a note without syncing.
2. Try to close or refresh the tab and confirm the browser warns about unsynced work.
3. Stay on the page.
4. Sync the note.
5. Run Backup Check.
6. Save a server-side backup.
7. Confirm the backup appears in the saved backup list.

## Mobile Width Flow

1. Open the app at a phone-sized viewport.
2. Use Home, Notes, Write, and Tools from the bottom bar.
3. Create a short note from mobile width.
4. Save it.
5. Confirm Tools exposes backup and security controls.

## End Of Day

1. Run Backup Check.
2. Confirm no missing attachments or thumbnails are reported.
3. Create a saved backup after meaningful writing.
4. Log out and log back in.
